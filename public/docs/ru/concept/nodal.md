# Nodal Wheel

Nodal Wheel — это тип Колеса, описывающий **узловой цикл** целевого тела относительно опорной плоскости.

Он моделирует моменты пересечения этой плоскости и отклонение тела к северу/югу между пересечениями.

Nodal Wheel — это не модель горизонта и не модель фазового угла.
Это **цикл широты относительно плоскости**.

---

## Какой вопрос он решает?

Для заданного момента `t`:

* Где находится ближайший предыдущий **восходящий узел**?
* Где находится ближайший следующий **восходящий узел**?
* Где расположен **нисходящий узел** между ними?
* Когда достигается максимальная северная и максимальная южная широта относительно опорной плоскости?
* В какой части текущего узлового цикла находится `t`?

Иными словами:

> Как target движется по северной и южной сторонам опорной орбитальной плоскости?

---

## Базовая идея

Nodal Wheel использует узловую широту:

* `lat_nodal(t) = asin( dot( u_target(t), n_ref(t) ) )`

Где:

* `u_target(t)` — единичный вектор от центра модели к target
* `n_ref(t)` — единичная нормаль опорной плоскости

Якоря цикла:

* **E**      — предыдущий восходящий переход (`lat_nodal` из `-` в `+`)
* **W**      — нисходящий переход внутри текущего цикла (`+` в `-`)
* **E+**     — следующий восходящий переход
* **N**      — максимум узловой широты на `[E, W]`
* **S**      — минимум узловой широты на `[W, E+]`

Канонический порядок:

E → N → W → S → E+

---

## Обязательные роли

Nodal Wheel требует:

* **looker**
* **focus**
* **target**

Target должен быть `engine_body` и не должен совпадать с телом центра модели.

---

## Поддерживаемые геометрические модели в `nodal.ts`

Текущий solver поддерживает две внутренние модели:

### 1) Pair model (тело + тело)

Используется, когда и `looker`, и `focus` являются `engine_body`.

* Нормаль опорной плоскости строится из орбитального движения пары looker-focus.
* Вектор target измеряется от focus.

### 2) Axis model (reference-ось + тело)

Используется, когда ровно одна из ролей (`looker` или `focus`) является `reference`, а вторая — `engine_body`.

* Нормаль опорной плоскости берется напрямую из направления reference-оси.
* Вектор target измеряется от опорного `engine_body`.

Если роли не попадают в одну из этих корректных комбинаций, solver возвращает ошибку ролей.

---

## Границы цикла

Nodal Wheel ограничен двумя восходящими узлами:

* **E** на или до `t`
* **E+** после `t`

Стратегия поиска:

* грубое сканирование + уточнение бисекцией
* экспоненциальное расширение окна (включая большие окна для медленных тел)

Далее solver находит:

* **W** как первый нисходящий переход внутри `[E, E+]`
* **N** как максимум широты на `[E, W]`
* **S** как минимум широты на `[W, E+]`

Если строгий порядок нарушен (`E < N < W < S < E+`), решение считается невалидным.

---

## Построение спиц (17 спиц)

Nodal Wheel возвращает 17 спиц:

* 0: `E`
* 4: `N`
* 8: `W`
* 12: `S`
* 16: `E_next`

Промежуточные спицы строятся через **интерполяцию по узловой широте между якорями**:

* В каждой четверти линейно интерполируется целевое значение широты.
* Затем решается уравнение `lat_nodal(t) = targetLat` внутри соответствующей четверти.
* Если локальный solve не сошелся, используется линейный fallback по времени внутри четверти.

Итоговые спицы строго монотонны по времени.

---

## Meta данных спицы

Каждая спица включает:

* `nodalLatitudeDeg`
* `distanceAu`
* `distanceKm`

Это позволяет UI показывать одновременно:

* геометрию узлового цикла (переходы север/юг),
* физическую дистанцию в каждой спице.

---

## Семантика тегов

Базовые теги из solver:

* `E-nodal`, `ascending node`
* `W-nodal`, `descending node`
* `N-nodal`, `max latitude`, `north apex`
* `S-nodal`, `min latitude`, `south nadir`
* `north side` / `south side` для промежуточных участков
* `cycle start`, `cycle end` и тег длительности цикла на `E`

Эти теги предназначены для композитных колес и для тултипов.

---

## Примеры

`Sun Nodal: Earth - Moon`

* looker: Sun
* focus: Earth
* target: Moon

Классический драконический-подобный цикл Луны относительно опорной плоскости Земля-Солнце.

`Earth Nodal: Sun - Pluto`

* looker: Earth
* focus: Sun
* target: Pluto

Длинный узловой цикл с широкими окнами поиска из-за медленного движения.

---

## Чем Nodal Wheel не является

Nodal Wheel — это не:

* цикл видимости относительно горизонта (Horizon)
* цикл угловой фазы (Synod)
* цикл только по расстоянию (Bind)

Он описывает **структуру пересечений плоскости и северо-южной широты орбитального движения**.
