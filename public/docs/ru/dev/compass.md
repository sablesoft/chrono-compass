# Compass - Техническое Задание

Всё ниже относится к реализации и не предназначено для обычного читателя.

## Component interface

Обычные циклические колёса:

* `<Wheel kind={kind} lat={lat} lon={lon} selectedTs={$selectedTsStore} />`

Компасное колесо:

* `<Compass lat={lat} lon={lon} selectedTs={$selectedTsStore} />`

Примечания:

* Compass не использует `kind`.
* `looker` — глобальная персистентная настройка (по умолчанию Земля).

## A) Состояние и персистентность

* Гарантировать существование только одного Compass Wheel.
* Персистентные состояния:

    * `looker`
    * сохранённые `observer`-локации по looker
    * `selectedTargets` и избранные
* Временные состояния:

    * `fixedTarget` (не более одного)

## B) Интеграция выбора локации

* Расширить `locationPicker` выбором `CelestialBody`.
* При смене looker:

    * мгновенно обновлять список локаций
    * при отсутствии — использовать локацию по умолчанию
* Встроить аналогичный picker в Compass Wheel.

## C) Геометрия и эфемериды

Для каждого тела:

* вычислять азимут [0..360)
* вычислять высоту [-90..+90]
* определять видимость

## D) Экранное отображение

* Рисовать линию горизонта с отступом внутрь.
* Соответствие:

    * азимут → угол
    * высота >= 0 → внутренний диск
    * высота < 0 → внешнее кольцо

## E) Маркеры

* Отрисовка маркеров тел.
* Группировка при близком расположении.

## F) Попапы

* Открытие по клику.
* Действия: фиксация, связанные колёса.

## G) Фиксация

* Двойной клик включает/выключает фиксацию.
* Фиксация эксклюзивна.

## H) Навигационный решатель

* Поиск моментов времени для заданного азимута.
* Выбор прошлое / будущее.

## I) Кнопки вперёд / назад

* Переходы по возвращению к тому же азимуту.

## J) Анимации

* MVP: мгновенные переходы.
* Далее: плавная анимация.

## K) Проверки корректности

* Экватор.
* Полушария.
* Видимость.
* Стабильность навигации.
