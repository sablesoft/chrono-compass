## Поведение при фиксации

### Важное архитектурное примечание

Каждое колесо некоторого типа выступает как шаблон (конструктор), с помощью которого пользователь может создавать и сохранять собственные конфигурации под удобными ему названиями.

Таким образом:

* тип колеса = системный шаблон;
* сохраненное колесо = пользовательская конфигурация данного шаблона.

---

### Адаптация управления под тип устройства

Необходимо определять тип устройства:

* Устройство с указателем/курсором (desktop).
* Сенсорное устройство (mobile / tablet).

Поведение:

* Для desktop:

  * Использовать hover.
  * Одиночный клик для действий.
* Для сенсорных устройств:

  * Использовать одиночный и двойной тап.
  * Не полагаться на hover.

Цель — обеспечить максимально естественное и удобное управление на каждой платформе.
