# ChronoCompass

## 🌐 Переводы

- 🇬🇧 **English (main)** — [../../README.md](../../README.md)
- 🇷🇺 **Русский** — этот документ

**ChronoCompass** — это визуальный инструмент исследования времени, который рассматривает время не как линейную шкалу, а как систему **направленных циклов**.

Вместо «когда?» ChronoCompass помогает ответить на вопрос: **«Где мы находимся во времени?»**

Приложение объединяет астрономические циклы, пространственную интуицию и единую компасную модель, позволяя видеть взаимное положение суток, Луны, года и более длинных циклов как вращающиеся колёса.

## 🧭 Основная идея

- Время — это **циклы**, а не прямая линия
- Циклы имеют **направления** (E / N / W / S)
- Несколько циклов существуют **одновременно**
- Их несовпадение, дрейф и резонансы — осмысленны
- Ориентация во времени возможна так же, как ориентация в пространстве

ChronoCompass использует **единую компасную модель** для отображения принципиально разных временных процессов.

---

## 🧠 Что делает ChronoCompass

- Визуализирует независимые временные циклы:
    - суточный (вращение Земли),
    - лунный синодический (фазы Луны),
    - лунный драконический (узлы и затмения),
    - лунный аномалистический (расстояние),
    - солнечный тропический (времена года),
    - солнечный аномалистический (перигелий / афелий),
    - прецессионный (Платонов год).

- Отображает каждый цикл как **колесо с 16 направлениями и домами**
- Позволяет:
    - перемещаться по времени вперёд и назад,
    - работать в LIVE-режиме (текущее время),
    - сохранять произвольные моменты времени,
    - создавать периодические события,
    - группировать события в коллекции.

- Учитывает **географическое положение** (широта / долгота)
- Работает **полностью оффлайн**
- Может быть установлено как **PWA**

---

## 🧩 Единая компасная модель

В основе проекта лежит **Unified Compass Model** — единый стандарт отображения времени.

Все циклы:
- имеют направления (спицы),
- разделены на дома,
- используют одинаковую геометрию,
- но не принуждаются к синхронизации.

Связь ключевых точек цикла с направлениями компаса:
- продумана физически и логически,
- не является произвольной,
- формирует устойчивое смысловое значение направлений
  (Восток, Север, Запад, Юг) **во всех циклах**.

## 🕰 Точность и расчёты

- Большинство циклов рассчитываются с точностью **до минуты**
- Используются реальные астрономические модели
- Граничные и полярные случаи обрабатываются явно

## 📍 Работа с локациями

- Можно задавать координаты вручную
- Сохранять несколько мест на Земле
- Быстро переключаться между ними
- Геолокация используется опционально

---

## 📦 Оффлайн и PWA

ChronoCompass:
- не требует интернета для работы,
- хранит данные локально,
- устанавливается как Progressive Web App,
- использует интернет только для:
    - обновлений,
    - автоматического определения координат (по желанию).
